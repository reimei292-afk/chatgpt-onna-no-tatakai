# 侍女キャラクター設定 — 第1ステージ

本ディレクトリは「チャットGPT・女の戦い」の侍女8人の参照資料と、ゲーム用キャラクター素材の配置先です。

## 共通デザイン規則
- 髪色は黒または茶系のみ。髪型・前髪・長さ・まとめ方で明確に差別化する。
- 共通衣装：白いレースのキャミソール、黒いテーパードパンツ、黒いパンプス、銀色のティアラ。
- ベルトは参考画像に合わせ、黒い細幅レザーベルト、長方形のシルバー色バックル、黒いベルトループ。ゲーム内の全員で同一形状を維持し、色・バックル形状・幅を変更しない。
- キャラクターごとに顔立ち、体格、姿勢、表情、髪型、戦闘時の構えを変える。
- 各キャラクターは前・後・左・右・斜め・上・下のカメラ方向に対応できるようにする。実装時は全方向で衣装・顔・髪型・ベルトを一貫させる。
- 兵種は弓兵／懐刀兵。懐刀兵の攻撃は刺突のみ。

## 推奨ファイル構成
各キャラクターは次の構成で高解像度の素材を保存する。

- `attendant-XX/turnaround.png` — 前・後・左右・斜めの全身資料
- `attendant-XX/portrait.png` — 顔・髪型・ティアラの資料
- `attendant-XX/poses.png` — 待機、歩行、弓構えまたは懐刀の刺突構え
- `attendant-XX/texture-notes.md` — 衣装、ベルト、髪の再現規則
