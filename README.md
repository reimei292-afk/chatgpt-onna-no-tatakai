# チャットGPT・女の戦い

侍女たちが模擬部隊戦を繰り広げる、ブラウザ向け戦術ゲームの試作版です。

## 第1ステージ：草原の櫓陣
- 20人対20人の模擬戦
- 味方陣地に櫓2基、敵陣地に井闌2基を配置
- 兵種：弓兵、懐刀兵（近接時の刺突攻撃）
- 若い日本人女性の侍女を想定した8人の初期キャスト
- 共通衣装：銀色のティアラ、白いレースキャミソール、黒いテーパードパンツ、黒いパンプス、黒い細幅ベルトと長方形の銀色バックル
- 戦闘開始・再戦・兵数・経過時間・戦況ログ

## 遊び方
`index.html` をブラウザで開き、「戦闘開始」を押してください。外部ライブラリやビルド工程は不要です。

## キャラクター素材
初期キャストと衣装・素材方針は [assets/characters/README.md](assets/characters/README.md) を参照してください。現在のステージはプレイ可能なプロトタイプで、最終品質の個別キャラクターモデルや多方向素材は今後の制作対象です。

## 公開
GitHub Pages の設定で公開元に **GitHub Actions** を選択すると、同梱のワークフローからサイトを公開できます。公開URLはリポジトリの **Settings → Pages** に表示されます。
